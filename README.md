# Logistics Data Analyst – Week 3

## Advanced Data Analysis and Visualization in Logistics using Python

This project fulfills the Yuva Intern Week 3 task using a reproducible **hypothetical logistics dataset**.

### Analysis covered
- Data simulation and structure definition
- Central tendency and descriptive statistics
- Delivery-time distribution
- Transportation cost analysis
- Monthly shipment trend
- Distance vs transportation cost
- Correlation analysis
- Delivery delay analysis
- Operational insights and recommendations

### Tools
Python, Pandas, NumPy, Matplotlib

### Dataset
The project simulates **1,500 logistics shipments** across five regions and four transport modes. The simulated dataset contains delivery, cost, distance, volume and delay variables.

### How to run
```bash
pip install -r requirements.txt
python week3_logistics_analysis.py
```

Outputs are generated in `week3_outputs/`.

### Note
The dataset is hypothetical/simulated, matching the Week 3 requirement for data simulation. No confidential company data is used.
