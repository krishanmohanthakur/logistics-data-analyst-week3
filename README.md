# Logistics Data Analyst – Week 3

## Advanced Data Analysis and Visualization in Logistics using Python

This project is part of the **Yuva Intern Logistics Data Analyst Internship – Week 3** task.

## Project Objective

The objective of this project is to perform advanced data analysis and visualization on logistics data using Python. The analysis focuses on understanding delivery performance, shipment volumes, transportation costs, delays, and relationships between important logistics variables.

## Dataset

The analysis uses the **Brazilian E-Commerce Public Dataset by Olist**, which contains e-commerce order, product, customer, seller, payment, freight, and delivery-related information.

The dataset is used to explore logistics performance and identify meaningful operational insights.

## Key Areas of Analysis

- Delivery time analysis
- Shipment volume analysis
- Freight and transportation cost analysis
- Delivery delay analysis
- Order and logistics performance analysis
- Central tendency analysis
- Distribution analysis
- Correlation analysis
- Identification of potential operational bottlenecks

## Exploratory Data Analysis (EDA)

The project includes:

- Mean, median and mode
- Minimum and maximum values
- Standard deviation
- Data distributions
- Outlier analysis
- Correlation analysis
- Trend analysis
- Relationship between logistics variables

## Visualizations

The project uses Python visualization libraries such as:

- Matplotlib
- Seaborn
- Pandas

The visualizations include:

- Bar charts
- Histograms
- Box plots
- Scatter plots
- Correlation heatmaps
- Time-based trend charts

Each visualization is selected according to the analytical question it helps answer.

## Business Insights

The analysis aims to identify:

- Factors affecting delivery performance
- Patterns in shipment volumes
- Major transportation cost drivers
- Potential delivery bottlenecks
- Distribution and outlier patterns
- Relationships between logistics performance indicators

These insights can support data-driven logistics and operational decision-making.
